# FreshBasket Market - Complete Website

A fully responsive replica of the FreshBasket Market grocery delivery website.

## Features Implemented

### Complete Sections
1. **Header** - Sticky navigation with logo and sign-in button
2. **Hero Section** - Main call-to-action with feature list
3. **How It Works** - 3-step process cards
4. **Shop by Aisle** - Product category cards with icons
5. **CTA Section** - Call-to-action for account creation
6. **Footer** - Copyright and tagline

### Responsive Design
- **Desktop (1024px+)**: Full layout with all elements side-by-side
- **Tablet (768px - 1024px)**: Adjusted spacing and font sizes
- **Mobile (< 768px)**: 
  - Hamburger menu navigation
  - Stacked layouts
  - Full-width buttons
  - Optimized touch targets

### Interactive Features
- Smooth scrolling navigation
- Hover effects on buttons and cards
- Mobile menu toggle
- Animated transitions

## Files Included
- `index.html` - Complete HTML structure
- `style.css` - Full styling with media queries

## How to Use
1. Open `index.html` in your browser
2. Test responsiveness by resizing the browser window
3. The mobile menu appears on screens smaller than 768px

## External Dependencies
- Phosphor Icons (for icons)
- Font Awesome (backup icons)
- Google Fonts (Poppins font family)
